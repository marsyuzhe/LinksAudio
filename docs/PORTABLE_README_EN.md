# Links Audio 1.0.0

By Links Tam. Extract the full ZIP and run LinksAudio.exe. Keep both DLLs and licenses/ beside the executable. No .NET Runtime, Node.js, Python or FFmpeg installation is required. Normal use is offline and local, with no login or upload interface.

Import files, choose MP3/WAV and an output folder, then start. Standard/Tencent SILK, MP3 and common PCM WAV are supported. True AMR decoding is not supported. Batch conversion, cancellation and basic playback are available. Input files are preserved.

Windows 10/11 x64 is the target. The current Windows machine was tested; clean Windows 10/N and broad real-recording coverage remain pending. A pre-release designation is recommended. See TEST_REPORT.md.
